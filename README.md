# Nation Supermarket
🚀 **Live Production Demo:** [https://nationsupermarket.eghedev.com](https://nationsupermarket.eghedev.com)  

👤 **Author:** Eghe Destiny
A modern online supermarket for Nigeria, allowing customers to browse products, buy products securely, and choose delivery or pickup.

## Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Backend:** Node.js, Express, TypeScript
- **Database:** PostgreSQL
- **Integrations:** Paystack, Cloudinary, SMTP

## Setup Instructions

Make sure you have Node.js and PostgreSQL installed.

### Backend Setup
1. Open terminal and navigate to the `backend` directory.
2. Install dependencies: `npm install`
3. Copy `.env.example` to `.env` and fill in your credentials.
4. Run the development server: `npm run dev`

### Frontend Setup
1. Open a second terminal and navigate to the `frontend` directory.
2. Install dependencies: `npm install`
3. Copy `.env.example` to `.env` if required.
4. Start the frontend: `npm run dev`
